# falaky-bot — قناة فيزياء الأجهزة

إنتاج آلي لحلقات عربية وثائقية عن **فيزياء الأجهزة الكهربائية والإلكترونية**،
يعمل على GitHub Actions والجهاز مطفأ، بتكلفة صفر.

## لماذا تغيّر المحرّك؟

النسخة الأولى كانت ترسم نصًّا عربيًا على خلفية متدرّجة — وهذا يبدو آليًا مهما
تحسّن الصوت. المحرّك الحالي يرسم **الفكرة نفسها**:

| قبل | بعد |
|---|---|
| نصّ على تدرّج لوني | مشاهد Manim مرسومة بالكود (محرّك 3Blue1Brown) |
| مقطع ١٤ ثانية | حلقة وثائقية ٥–٨ دقائق ببنية أقسام |
| تقسيم الزمن تخمينًا | تعليق منفصل لكل مشهد ⇒ تزامن مضمون بالبناء |
| موسيقى بمستوى ثابت | ducking: الموسيقى تنخفض تلقائيًا تحت الكلام |
| لقطات ستوك عشوائية تتكرّر | لا تكرار؛ الستوك اختياري وليس العمود الفقري |

## البنية

```
src/content.py   كتابة السكريبت (خطّاف + أقسام + توجيه بصري) عبر Gemini
                 مع حلقتين احتياطيّتين كاملتين تعملان بلا أي مفتاح
src/voice.py     تعليق edge-tts لكل جزء على حدة + قياس مدّته
src/audio.py     رصف الخط الزمني + موسيقى بـducking دقيق
src/scenes.py    مكتبة مشاهد Manim: flow / bullets / compare / wave / orbit / stat
src/visuals.py   تشغيل Manim لكل قسم، وبديل بطاقات مصمَّمة إن تعذّر
src/design.py    نظام التصميم: الألوان، الخط، تشكيل العربية
src/render.py    التركيب النهائي
src/main.py      المنظّم
src/footage.py   (اختياري، غير مستعمل حاليًا) لقطات ستوك مجانية
```

## التشغيل

```bash
pip install -r requirements.txt
python src/main.py              # ينتج output/video.mp4
python src/main.py --publish    # ينتج ويرفع على يوتيوب
```

على GitHub: تبويب **Actions** ← `produce-video` ← **Run workflow**.
الجدولة الحالية: **حلقة أسبوعية** (الأربعاء) — الجودة قبل الكمّية.

### متطلّبات النظام محليًا

```bash
sudo apt install ffmpeg pkg-config python3-dev \
     libcairo2-dev libpango1.0-dev fonts-hosny-amiri
```

## الأسرار (GitHub Secrets)

| السرّ | إلزامي؟ | الغرض |
|---|---|---|
| `GEMINI_API_KEY` | لا | كتابة سكريبت جديد؛ بدونه تُستعمل الحلقات الاحتياطية |
| `YT_CLIENT_ID` / `YT_CLIENT_SECRET` / `YT_REFRESH_TOKEN` | لا | الرفع التلقائي ليوتيوب |
| `PEXELS_API_KEY` / `PIXABAY_API_KEY` | لا | لقطات ستوك (غير مستعملة حاليًا) |

## الموسيقى

ضع ملفًّا باسم `assets/music.mp3` (من مكتبة يوتيوب الصوتية أو Pixabay Music).
بدونه يعمل الفيديو بالتعليق فقط — لكن إضافتها أرخص قفزة جودة في المشروع.

## الضبط

كل شيء في `config.json`: الألوان، الخط، الصوت، طول الحلقة، النيتش.
لتغيير الهوية البصرية للقناة كلّها، غيّر `design` فقط.
