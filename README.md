# falaky-bot — قناة فيزياء الأجهزة

إنتاج آلي لحلقات عربية وثائقية (٢٠ دقيقة فأكثر) عن **فيزياء الأجهزة
الكهربائية والإلكترونية**، يعمل على GitHub Actions والجهاز مطفأ، بتكلفة صفر.

## ما تضمنه كل حلقة

- **شرح دقيق** خطوة بخطوة، لا إشارات عامّة
- **مثال ملموس** من حياة المشاهد اليومية في كل قسم
- **مخاطبة المشاهد** مباشرةً: تخيّل، لاحظ معي، جرّب
- **أصل الفكرة**: من لاحظها، وكيف صارت من اكتشاف إلى اختراع
- **العلماء** بأسمائهم وتواريخ حياتهم وإسهاماتهم
- **خط زمني** يربط المحطّات بالسنوات

## كيف يعمل

### ١) سكريبت على مرحلتين
طلب ٣٠٠٠ كلمة في نداء واحد يصطدم بحدّ التوكنز ويُخرج نصًّا سطحيًا.
فنطلب **المخطّط** أولًا، ثم نوسّع **كل قسم في نداء مستقل**.

### ٢) رسم متوازٍ
٢٠ دقيقة من Manim في خادم واحد = ساعات. لذلك يُرسم **كل قسم في خادم
مستقلّ** عبر matrix، فيصير زمن الانتظار بطول **أطول قسم** لا بمجموعها.

```
script (سكريبت + تعليق) → render ×N بالتوازي → assemble (تركيب + نشر)
```

### ٣) تزامن مضمون بالبناء
نولّد تعليقًا منفصلًا لكل قسم، فنعرف مدّته قبل الرسم، ثم يُرسم المشهد
بتلك المدّة بالضبط. لا تخمين ولا انزلاق.

## أنواع المشاهد

| النوع | لماذا |
|---|---|
| `flow` | سلسلة مراحل (يمين ← يسار) |
| `bullets` | نقاط تُكشف تباعًا |
| `compare` | مقارنة خيارين بميزة وثمن |
| `wave` | موجة متحرّكة للتردّد والإشارة |
| `orbit` | ذرّات وإلكترونات |
| `stat` | رقم واحد كبير |
| `timeline` | خط زمني للاكتشاف والاختراع |
| `profile` | بطاقة عالِم: اسم، سنوات حياته، إسهامه |
| `quote` | اقتباس مع قائله |

بطاقات العلماء **بلا صور** — هوية خطّية فقط، تجنّبًا لمشاكل حقوق الصور.

## البنية

```
src/content.py   مخطّط ثم توسيع كل قسم (Gemini) + حلقة احتياطية
src/voice.py     تعليق edge-tts لكل جزء + قياس مدّته
src/audio.py     رصف الخط الزمني + موسيقى بـducking دقيق
src/scenes.py    مكتبة مشاهد Manim (٩ أنواع + بطاقة عنوان)
src/visuals.py   render_one: وحدة رسم مستقلّة تسمح بالتوازي
src/design.py    نظام الألوان والخطوط + بطاقة بديلة مصمّمة
src/render.py    التركيب النهائي
src/main.py      المنظّم (مراحل)
```

## التشغيل

على GitHub: **Actions** ← `produce-video` ← **Run workflow**.
الجدولة: **حلقة أسبوعية** (الأربعاء).

محليًا:

```bash
sudo apt install ffmpeg pkg-config python3-dev \
     libcairo2-dev libpango1.0-dev fonts-hosny-amiri
pip install -r requirements.txt

python src/main.py                      # كل المراحل
python src/main.py --stage script
python src/main.py --stage render --index 3
python src/main.py --stage assemble --publish
```

## حصّة Gemini — انتبه

كل حلقة تستهلك **نداءً واحدًا للمخطّط + نداءً لكل قسم**، أي نحو
**١١ إلى ١٥ نداءً**. على الطبقة المجانية ذات الـ٢٠ نداء يوميًا، هذا يعني
**حلقة واحدة يوميًا كحدّ أقصى**. الجدولة الأسبوعية مريحة جدًا ضمن ذلك.

لتقليل الاستهلاك: أنقص `episode.max_sections` في `config.json`.

## الحلقة الاحتياطية

إن تعذّر Gemini (لا مفتاح، أو نفاد الحصّة) يُستعمل سكريبت احتياطي مكتوب
يدويًا عن تاريخ البطارية. طوله **نحو ٤ دقائق لا ٢٠**، ولهذا **لن يُنشر
تلقائيًا** — يُحفظ كأثر لتراجعه بنفسك. هذه شبكة أمان، لا بديل.

## الأسرار (GitHub Secrets)

| السرّ | إلزامي؟ | الغرض |
|---|---|---|
| `GEMINI_API_KEY` | عمليًا نعم | بدونه لا توجد حلقات ٢٠ دقيقة |
| `YT_CLIENT_ID` / `YT_CLIENT_SECRET` / `YT_REFRESH_TOKEN` | لا | الرفع التلقائي |

## الموسيقى

ضع `assets/music.mp3` (من مكتبة يوتيوب الصوتية أو Pixabay Music).
الموسيقى تنخفض تلقائيًا تحت الكلام (ducking) وتعلو في الفراغات.

## الضبط

كل شيء في `config.json`: طول الحلقة، عدد الأقسام، الألوان، الخط، الصوت، النيتش.
لتغيير الهوية البصرية للقناة كلّها، غيّر `design` فقط.
